ZARAGOZA AIRE — PWA v0.8 · Incremento experimental

Origen: v0.7 funcionalmente aceptada.

Novedad: consulta bajo demanda de histórico horario para O3 (código 5) y PM10 (código 6), códigos documentados expresamente en el catálogo municipal.

La estructura exacta de respuestas actuales de la API histórica no ha podido verificarse desde el entorno de construcción. La v0.8 NO está aceptada: se necesita probarla en Edge antes de publicarla. La consulta de históricos podría fallar por CORS, por el formato del JSON, por campos de fecha o por falta de datos. No se inventan gráficas.

Para publicar, sustituir los seis archivos en la raíz de GitHub Pages. Primero probar en entorno local HTTPS/localhost o sitio de ensayo, para preservar la v0.7 estable.

Criterios: 12/24 horas para gráfica, 18/24 para media descriptiva. Huecos no interpolados. Sin comparación normativa ni alerta sanitaria.

Validaciones: sintaxis JS, estructura HTML y ZIP. No se ha podido probar una respuesta real del servicio horario.

CORRECCIÓN v0.8.3: la API horaria requiere idSparql (p.ej. Actur=40), no id de listado (Actur=12). Se conserva v0.7 publicada hasta validación de esta versión.

CAMBIO v0.8.3: El lector histórico reconoce las series por contaminante (O3, PM10), incluidas las listas JSON serializadas en texto. Distingue series vacías de respuestas con estructura desconocida.
