Evolución de las últimas 24 horas

Serie horaria municipal por estación y contaminante. Se utilizan las observaciones horarias fechadas de la API municipal; la disponibilidad varía por estación y contaminante. Solo se dibuja con 12 o más horas válidas; solo se calcula una media descriptiva con 18 o más horas válidas. Las ausencias no se interpolan. No se calculan índices, superaciones legales ni alertas sanitarias.

Selecciona una estación y pulsa «Consultar evolución». La evolución se calcula exclusivamente a partir de observaciones con magnitud, fecha y valor verificados. Las estaciones sin registros de la magnitud seleccionada se muestran sin gráfica.

Fuente y diagnóstico de la serie horaria

API oficial: /sede/servicio/calidad-aire/estacion/horaria.json. Consulta bajo demanda, sin almacenar histórico.

Cómo interpretar las mediciones

La clasificación oficial es la del Ayuntamiento. Las explicaciones de cada contaminante son orientativas; no sustituyen la información oficial ni representan alertas sanitarias. Una lectura puntual no se puede comparar directamente con una recomendación de 8 o 24 horas, ni sirve para determinar el cumplimiento de un límite anual o legal.

Abre «Interpretar medición» dentro de cada tarjeta para conocer el contaminante y sus referencias. Se muestran por separado las recomendaciones de la OMS (2021), los valores de la UE anteriores al nuevo régimen y los valores previstos para 2030. Los límites legales incluyen reglas adicionales sobre promedios y número permitido de superaciones; esta aplicación no los evalúa.

Fuentes: OMS, directrices 2021 · Directiva (UE) 2024/2881, anexo I.

Fuente y diagnóstico

Servicio: API pública municipal de estaciones y observaciones. Las mediciones son provisionales y no representan necesariamente la calidad del aire de cada calle. Los colores proceden de la clasificación publicada por el Ayuntamiento, no constituyen una alerta sanitaria emitida por esta aplicación.

¿No funciona la conexión directa?

Abre el enlace oficial, guarda el JSON y selecciónalo aquí para probar la interfaz sin servidor. El archivo se procesa localmente y no se envía a ningún sitio. Se conserva en este dispositivo únicamente la última respuesta válida de la API en directo (no el histórico ni archivos importados). Puedes eliminarla aquí.
